# 历史范围

此仓库从一次干净初始提交开始，不上传原开发仓库的 Git 历史、聊天记录或部署记录。

| 阶段 | 收录范围 |
| --- | --- |
| 早期 experiment | `simulation/` 的控制、搜索、结果与四组历史评估 |
| r4、r5 | `simulation_v2/archive/` 的主要源码、配置和结果；不收录每次回放副本 |
| r6 短期中断 | 中断声明、原结果和主要源码，保留中断事实 |
| r6 完整 100 代 | 当前 v2 源码、候选账本、评估账本、全部检查点及审计 |
| v3 | 人工四元数修复、冻结基线、预测器、分配器、固定集与新种子验证 |
| v4 | 当前 60 代训练的全部候选、种子、开发集、检查点、验证、步长复查和演示 |
| 驾驶沙盒 | 2026-10-22 的已提交前端快照，再做中性命名、路径整理及去贴图改动 |

公开副本不包含每个临时控制器草稿、不完整探索分支、工具输出缓存或所有失败轨迹录像。完整候选和验证指标保留的是上表明确收录的最终实验批次，不暗示记录了全部开发尝试。

排除官方媒体、用户截图、纹理、照片衍生底盘贴图、模型备份、多个旧站点副本、离线部署压缩包、安装环境、构建依赖和私人配置。默认模型是当前精修版本的无贴图导出，不把带贴图原件藏在 Git 历史或归档里。

`export-provenance.json` 保留所选原文件的哈希与相对来源。`export-changes.json` 标明副本与原文件不同之处；冻结实验控制核心没有为品牌清理而改写。解压后可把源文件、种子和结果相互核对。
